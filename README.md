**Fecha:** 13/09/2026

## Contenido del Repositorio
Este repositorio contiene la resolución de los problemas prácticos asignados en el laboratorio. Incluye aplicaciones desarrolladas en C# que abarcan tanto lógica en aplicaciones de consola como el diseño y manejo de eventos mediante interfaces gráficas en Windows Forms (ej. manejo de un DataGridView con listas dinámicas).

## Tecnologías Utilizadas
* **Lenguaje:** C#
* **Framework:** .NET Framework / .NET (Windows Forms y Consola)
* **IDE:** Visual Studio
* **Herramientas:** Git, GitHub

### Problemas / Ejercicios Desarrollados
* **Ejercicio 1 (Windows Form - [DataGrid]):** Uso de la herramienta toolStripButton para agregar, modificar y eliminar elementos de la plantilla contenida en un DataGridView para la simulacion de la BD*
* **Ejercicio 2 (Aplicacion de Consola - [Juego de Craps]):** Juego de craps que esta recreado en consola donde se destaca el uso de aleatoriedad para la realizacion del juego*
* **Ejercicio 3 (Windows Form - [MDI]):** Uso de MDI(Multi Document Interface), para iniciar al estudiante en el manejo de diferentes ventanas dentro de una ventana padre en C#*
